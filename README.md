**IMPORTANT**
run py -m venv thesisenv to create virtual environment.

run pip install requirements.txt to install requirements.

look at https://www.jupedsim.org/stable/ for jupedsim documentation

***HOW TO RUN***
1. If not yet activated, activate env: `thesisenv\Scripts\activate.bat`
2. If not yet on sim_server folder, run `cd sim_server`
3. run `py main.py` 
4. Open Godot. Run main scene.
